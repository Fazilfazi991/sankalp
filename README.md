# Sankalp Branding Solutions Website

Production foundation for Sankalp's B2B catalogue and lead-generation website.

## Local development

```bash
pnpm install
pnpm dev
```

Validation:

```bash
pnpm lint
pnpm typecheck
pnpm build
```

Business contact details, canonical URL, products and operational claims remain intentionally unset until client verification. See `docs/client-data-needed.md` and `docs/asset-requirements.md`.
